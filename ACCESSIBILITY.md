# Accessibility Notes

SkillCred 0.3.0 provides a command-line and JSON API; it does not include a graphical interface.

- CLI messages are plain text/JSON and do not rely on color to convey success or failure.
- `SKILLCRED_LANG` and API `Accept-Language` support `ru`, `en`, `de`, `fr`, `es`, `zh`, and `ar` message selection, with locale-region fallback. Arabic is tagged RTL in i18n metadata. The CLI remains text/JSON-based and has no color-only status indicator.
- The CLI is keyboard-driven and has no mouse-only interactions.
- JSON output is structured for screen readers and script consumption; commands should not emit decorative animation or ANSI-only meaning.
- The API's interactive docs are generated by FastAPI; deployment teams should test them with keyboard navigation and screen readers before public use.
- Contrast and font-size checks do not apply to CLI text in the same way as a web UI. No claim is made that the generated API documentation has passed a formal WCAG audit.
- Pilot forms must be provided in an accessible format by each participating organization and should allow alternatives to signed paper forms where legally appropriate.

Accessibility check before release: run CLI commands under a terminal screen reader, verify structured JSON remains available, test keyboard-only navigation in `/docs`, and obtain feedback from people using assistive technology.
