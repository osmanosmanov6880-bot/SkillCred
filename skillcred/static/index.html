01 / Интерактивное демо

Подпись можно проверить.
И отзыв — тоже.

Пройдите цикл на демонстрационном удостоверении: выпуск, проверка подписи, отзыв и повторная проверка статуса. Не вводите реальные персональные данные.

Создайте тестовый бейдж

Демо использует живой API SkillCred: сервер выпускает настоящий подписанный JSON-LD документ, а проверка читает реальный статус Bitstring Status List. Секретные токены в браузер не передаются.

Готово к демонстрации. Нажмите «Создать демо-бейдж».

Что произошло
1. Создано
Организация подписывает цифровое подтверждение закрытым ключом Ed25519.
2. Доказано
Проверка пересчитывает подпись и отдельно оценивает статус отзыва.
3. Что это значит
Подпись может подтвердить целостность документа, но сама по себе не доказывает законность эмитента или качество оценки.
Подтверждение подписывается на сервере. Проверка использует актуальный подписанный список отзыва; после отзыва документ сохраняет криптографическую подпись, но уже не считается действительным.

Пример запроса
Пример требует токен издателя, заданный только в защищённом окружении.
curl -X POST "$SKILLCRED_URL/issue" \
  -H "Authorization: Bearer $ISSUER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"achievement_name":"Practical safety","achievement_description":"Completed a practical assessment."}'
Проверка выполняется через POST /verify с полем credential и токеном роли verifier. Токены предназначены только для серверных интеграций; не помещайте их в код браузера.
