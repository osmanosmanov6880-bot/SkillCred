Что произошло
1. Создано
Организация подписывает цифровое подтверждение закрытым ключом Ed25519.
2. Доказано
Проверка пересчитывает подпись и отдельно оценивает статус отзыва.
3. Что это значит
Подпись может подтвердить целостность документа, но сама по себе не доказывает законность эмитента или качество оценки.
Локальная демонстрация: подпись Ed25519 настоящая; статус отзыва хранится только в памяти этой вкладки и не публикуется как реальный Bitstring Status List.

API использует ролевую авторизацию. Не вставляйте рабочие bearer-токены в браузер, клиентское приложение или публичный пример кода.

Open Badges 3.0-shaped pilot · W3C Data Integrity · Ed25519 · did:key.
Профиль экспериментальный. Совместимость с официальным профилем Open Badges и криптосхемой сертификации не подтверждена; SkillCred не сертифицирован 1EdTech. Не используйте пилот для решений с существенными последствиями.
Пример запроса
Пример требует токен издателя, заданный только в защищённом окружении.
curl -X POST "$SKILLCRED_URL/issue" \
  -H "Authorization: Bearer $ISSUER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"achievement_name":"Practical safety","achievement_description":"Completed a practical assessment."}'
Проверка выполняется через POST /verify с полем credential и токеном роли verifier.
