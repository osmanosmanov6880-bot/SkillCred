# Support

SkillCred 0.3.0 is an experimental pilot project, not a certified credentialing platform.

- Usage and setup: read `README.md` and `pilot/runbook.md` first.
- Defects: open a GitHub issue using the bug report template, excluding tokens, private keys, credentials containing real personal data, and private logs.
- Security concerns: follow `SECURITY.md`; do not file exploitable details publicly.
- Standards/interoperability: include the target Open Badges/VC version, validator name/version, sanitized artifact and exact error message.
- Governance concerns: use the documented private appeal/contact route. Do not post personal details publicly.

No service-level guarantee is offered for this pilot. Support requests are handled on a best-effort basis.
